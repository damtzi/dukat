## Agent skills

### Issue tracker

Issues for this repo are tracked in GitHub Issues and should be managed with the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

This repo uses the default triage label vocabulary: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, and `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

This repo is configured as single-context: use the root `CONTEXT.md` and `docs/adr/` when present. See `docs/agents/domain.md`.
