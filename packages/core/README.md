# @repo/core

Shared schemas and types for this template.

The current package contains example domain schemas only. Replace them with your project's real domain model once you start building a product.

## Guidelines

- Keep schemas close to the language in `CONTEXT.md`.
- Export stable TypeScript types from each schema module.
- Re-export public modules from `src/index.ts`.
- Treat this package as the source of truth for domain types shared by apps, API routes, and clients.
